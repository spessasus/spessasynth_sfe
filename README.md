# SpessaSynth SFe

SFe (SF-Enhanced) 4.0 is a sound bank format that extends SoundFont 2.04. This repository holds its
[specification](https://spessasus.github.io/spessasynth_sfe/spec.html) and its
[compliance tests](https://spessasus.github.io/spessasynth_sfe/tests.html).

The specification is a release candidate of 4.0: it is published for review and may still change before the final
4.0. Feedback is welcome in the [issue tracker](https://github.com/spessasus/spessasynth_sfe/issues).

Some of my original ideas for the format are more than [2 years old](https://github.com/SFe-Team-was-taken/SFE/issues/6).

## Why SFe

SoundFont 2 is simple and widely supported, but it leaves a lot to the synthesizer and stops short of what classic
General MIDI hardware could do. SFe adds generators (a second modulation envelope, LFO waveforms and start phases, a
filter type, a voice delay and more), custom modulator curves, default modulators stored in the bank, 64-bit chunk
sizes and a defined MIDI behavior, so a bank sounds the same in every synthesizer that reads it.

Every SFe feature extends a stage that SoundFont 2 already has and defaults to the SoundFont 2 behavior. A bank without
any SFe feature can always be written as a valid SoundFont 2 file.

SFe is a public domain format. The specification is dedicated to the public domain under CC0 1.0, so anyone may
implement it, extend it or copy it, without asking and without attribution.

> SpessaSynth SFe (with a lowercase "e") is not SFE (with an uppercase "E") by the
> [SFE Team](https://sfe-team-was-taken.github.io/SFE/). The two formats share a name and many ideas, but a bank made
> for one is not a valid bank for the other.

## Specification

[Read it online](https://spessasus.github.io/spessasynth_sfe/spec.html) or download it as a
[PDF](https://spessasus.github.io/spessasynth_sfe/spessasynth-sfe-specification-4-0-rc.pdf). The source is
[`spec/sfe-format.md`](spec/sfe-format.md), a single Markdown file, and the build generates the page and the PDF from
it.

[spessasynth_core](https://github.com/spessasus/spessasynth_core) is the reference implementation. It reads, writes
and plays SFe files.

## Tests

The tests come in groups. Each group is a bank (`.sf4`), a MIDI file that plays it and a reference render (FLAC) made
by spessasynth_core, except the groups whose bank a reader must reject, which have a bank and a MIDI file but no reference render. Load the bank in the synthesizer under test, play the MIDI file and compare the result with the
pass criterion of each test. Every criterion can be checked without the reference render.

What every test plays and how it passes is listed on the
[tests page](https://spessasus.github.io/spessasynth_sfe/tests.html) and in `TESTS.md` inside the zip. Everything is
generated by code, and no sample, bank, MIDI file or render is committed. The files are the assets of the
[`latest` release](https://github.com/spessasus/spessasynth_sfe/releases/tag/latest).

## Building

Node 24 or later.

```sh
npm install
npm run build
```

Files are written into `dist/`, the PDF of the specification included. The build prints it with a headless Chromium
that `npm install` downloads.
